# Fotos dos serviços

Coloque as fotos originais aqui, cada uma na pasta do serviço correspondente.
Fotos de equipe, veículo ou que não se encaixam em nenhum serviço vão em `geral/`.

- Pode subir no tamanho original (JPG, PNG, HEIC ou WEBP): o site otimiza na hora de publicar.
- Se não souber a pasta certa, coloque em `geral/`.

Esta pasta não é publicada como está: as fotos são otimizadas e colocadas nas páginas do site.
